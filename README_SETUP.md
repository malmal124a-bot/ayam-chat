# Ayam Chat - Flutter Ready UI Project

This package contains the full Flutter-ready UI source:
- lib/
- assets/Asad/
- pubspec.yaml
- analysis_options.yaml

## Final setup on your machine
After extracting the zip, run:

1. flutter create .
2. flutter pub get
3. flutter run

This will generate the missing native folders like:
- android/
- ios/
- web/

## Notes
- Asset paths are already configured under assets/Asad/
- UI includes login, home, room, VIP, profile, settings, messages, gifts, combo, room admin logic
